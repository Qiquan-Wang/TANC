5 Analysis

Trains while capturing a snapshot every epoch, recomputes persistent homology at each one, and plots the chosen quantity against epoch.

Trains a population of networks, then runs Mapper across a grid of cover and clustering parameters. Every graph is reported alongside the nerve of its own cover, so b1_excess separates a real finding from an artefact of the cover.

Each layer × view pair becomes its own point cloud, so the grid grows multiplicatively.

On a 2-D weight — a linear layer, an embedding table, an attention projection — these read the matrix directly.

A convolutional weight has four axes, so “row” names no particular one. Each view here says which axes index points; the rest become that point’s coordinates. rows and cols are the rows and columns of the kernel itself. A Conv1d kernel has h = 1, so cols there is refused rather than returning points of dimension 1.

A 1-D lens gives an interval-chain cover whose nerve has b1 = 0, so there b1_excess = b1 exactly — do not compare b1_excess across lenses of different dimension.

Applied before the lens, because it changes the distances the clusterer sees. preprocess= in the toolkit.

l2 normalise puts every point on the unit sphere, so the clusterer sees direction rather than magnitude — use it when the structure you are after is in the shape of a point and not its size. One caveat: points with zero norm cannot be placed on the sphere and stay at the origin, where they are coincident with each other and will bind into a single node.

Applied after the lens, with the cover pinned to the unfiltered lens range — otherwise removing points shrinks the cover with them and the comparison measures nothing. point_filter= in the toolkit.

Overlap is |I ∩ I'| / |I| — the fraction of a cover interval shared with its neighbour. Interval width diverges as it approaches 1, so 1 is excluded.

Trains a second population with the same seeds for 0 epochs, so each trained network is paired with its own initialisation. Without it there is nothing to compare against, and a structure found in the trained weights cannot be shown to come from training. Doubles the number of clouds.

Being automatic is not the same as being right: an automatic rule still has to pick a scale, and the wrong scale either fuses the cloud into one node or shatters it into dust. Read n_components and cpc_mean whichever option you choose.

first-gap needs no threshold: it cuts each cell's dendrogram at the first decisive gap, so cells in dense and sparse regions get different cuts. It is the classical Mapper rule. Pair it with single linkage to follow thin, curve-like structure — the compact linkages (complete, average, ward) tend to cut across such a structure rather than along it.

⚠️ eps at the k-NN elbow is the other automatic option, but on curve-like data it tends to land at the noise scale rather than the structure scale, which shatters the graph into many components. Prefer first-gap, or sweep quantiles and look for the plateau where b1 holds steady.
