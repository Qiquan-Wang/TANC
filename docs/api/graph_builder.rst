GraphBundle
-----------

``GraphBundle`` inherits ``.save()`` / ``.load()`` — see :doc:`persistence`.
It is documented above, under its public ``tanc.graph_builder`` path; the
private ``_bundle`` module is deliberately not documented separately, so
cross-references resolve to a single target.
