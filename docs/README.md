# Building these docs

The published site is built from this directory by
`.github/workflows/docs.yml` on every push to `main` and served from GitHub
Pages. Nothing under `_build/` or `_generated/` is committed — both are
regenerated by every build.

To build locally:

```bash
pip install -e ".[docs]"

# Linux / macOS
make html

# Windows
make.bat html
```

Then open `_build/html/index.html`.

## Contents

* `index.rst` — landing page and table of contents.
* `getting_started.md` — includes the top-level `README.md`.
* `composing.rst` — the four-axis mental model and compatibility matrix.
* `parameters.rst` — valid values for every `builder_kwargs` / `tool_kwargs`.
* `pipeline_overview.rst` — `TDAPipeline` API and the result accessors.
* `sweep_overview.rst` — Mapper parameter sweeps and `b1_excess`.
* `visualisation_overview.rst` — plot catalogue with autosummary.
* `tutorial.ipynb` — the end-to-end hands-on tour.
* `notebooks/` — one rendered notebook per `from_paper` preset.
* `api/` — auto-generated API reference for each module.

## Build environment

Heavy runtime dependencies (`torch`, `tensorflow`, `gudhi`, `persim`, `gtda`,
`umap`, …) are listed in `autodoc_mock_imports` in `conf.py`, so the build
works in a stripped environment — CI installs only `sphinx`, `myst-nb`,
`furo`, `numpy` and `pandas`.

`nb_execution_mode = "off"`, so notebooks render from their stored outputs and
are never re-executed at build time. To refresh a notebook's figures, run it
yourself and commit the result.
