# =============================================================================
# GPU NOTES (the package NAMES above are identical on every OS) ----------------
#
# PyTorch:
#   * Apple Silicon (M1-M4): the standard `torch` wheel ABOVE already contains
#     the MPS/Metal backend. NOTHING extra to install, SAME version. Use it via
#     `tensor.to("mps")` / `device="mps"`.
#   * NVIDIA GPU (Windows/Linux): replace the torch lines with the CUDA build,
#     e.g.  pip install torch==2.2.2 torchvision==0.17.2 \
#             --index-url https://download.pytorch.org/whl/cu121
#     (Mac never uses CUDA.)
#
# TensorFlow:
#   * Apple Silicon GPU: see requirements-mac-gpu.txt (adds tensorflow-metal).
#   * Windows: TF > 2.10 has NO native GPU support — CPU only unless you run
#     under WSL2 with CUDA. The wheel above runs fine on CPU.
#   * Linux + NVIDIA: `tensorflow==2.16.2` includes CUDA support out of the box
#     (given a working CUDA/cuDNN driver stack).
# =============================================================================
